## Cập nhật bản ghim

Chạy lại bước 2–4 của phiếu 091 với pin mới. Từ gốc repo game, đoạn sau
chép bảy file từ lịch sử Git của repo cha, cập nhật config rồi sinh manifest
với khóa file theo thứ tự mã ký tự, thụt hai dấu cách và xuống dòng cuối:

```bash
VOCAB_PIN=<commit-mới-đủ-40-ký-tự> python3 - <<'PY'
import hashlib, json, os, subprocess
from pathlib import Path

pin = os.environ['VOCAB_PIN']
assert len(pin) == 40 and all(c in '0123456789abcdef' for c in pin)
files = ['index.json', *[f'levels/{n:03}.json' for n in range(1, 6)], 'ATTRIBUTION.md']
target = Path('public/vocabulary')
for name in files:
    path = target / name
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(subprocess.check_output([
        'git', '-C', '../..', 'show', f'{pin}:shared/vocabulary/{name}'
    ]))
config = {'pin': pin, 'files': files}
manifest = {
    'pin': pin,
    'version': json.loads((target / 'index.json').read_text())['version'],
    'files': {
        name: hashlib.sha256((target / name).read_bytes()).hexdigest()
        for name in sorted(files)
    }
}
for path, value in [(Path('vocab.config.json'), config), (target / 'vocab-manifest.json', manifest)]:
    path.write_text(json.dumps(value, indent=2) + '\n')
PY
```

Đoạn cập nhật dùng bố cục repo cha hiện tại. Repo game đứng riêng vẫn test
và build được bằng bản chép đã ghim, không cần chạy lệnh cập nhật này.
Sau cập nhật, chạy lại `pnpm check`, `pnpm td:golden:check` và kiểm đứng riêng.
Nếu hash bộ bài thay đổi, phải duyệt thay đổi từ vựng và replay trước khi
đổi hash kỳ vọng; không cập nhật golden tự động.
